# Direct visuals

Use `apply-design-taste` and read the project taste profile first. Produce `.figma-orchestrator/artifacts/direction.md` using `${CLAUDE_PLUGIN_ROOT}/templates/direction.md`.

Translate the strategic idea into operational choices: grid, density, rhythm, typography roles, color roles, imagery, shape language, components, motion character, and signature moments. A reference is evidence for a trait, not permission to copy its layout or expression.

Reject directions held together only by fashionable surface treatments. Treat trends as candidates filtered through the brief, not automatic signs of quality. Challenge generic card grids, arbitrary gradients, decorative blobs, excessive pills, interchangeable SaaS dashboards, unsupported glass effects, giant empty sections, and imagery that misrepresents the product.

Declare whether the direction needs a shader. Default to `none`. If proposed, define its conceptual job, placement, kind, palette, controls, motion, static fallback, accessibility boundary, and implementation value before direction approval.

Propose the smallest concept set that can test the direction. Usually this is two meaningfully different approaches across a hero or primary screen plus one representative content section. Variants must differ in concept and hierarchy, not only color.
