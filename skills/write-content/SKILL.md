# Write content

Produce `.figma-orchestrator/artifacts/content.md`, organized by page and section. Fit copy to the approved hierarchy instead of letting prose dictate accidental layout.

Use specific, credible language. Keep one primary action per decision point and define secondary actions only when they serve a distinct user need. Label unknown claims and proof requirements; never invent numbers, clients, reviews, awards, certifications, or quotes.

Include error, empty, success, loading, helper, and confirmation text when the product flow requires them. Mark provisional content clearly so it cannot be mistaken for client-approved truth.
