# Plan UX

Read the approved brief and strategy. Produce `.figma-orchestrator/artifacts/ux.md` using the UX contract.

For each page or screen define its user question, business purpose, entry context, primary action, required proof, content order, interactions, states, and mobile priority. Make dependencies and repeated modules explicit.

Prefer the smallest structure that fully serves the user and conversion goal. Do not add pages or sections because they are conventional. Explain every non-obvious hierarchy decision using audience need, message priority, or implementation constraint.

Flag flows that require authentication, data, legal review, CMS behavior, or unavailable content.
