# Apply design taste

Taste is contextual judgment, not a house-style preset. Start from the approved brief, strategy, audience, content, product reality, and brand assets. A current trend may influence the work only when it strengthens those inputs.

Before visual direction, read [taste-framework.md](references/taste-framework.md) and produce `.figma-orchestrator/artifacts/taste.md` using `${CLAUDE_PLUGIN_ROOT}/templates/taste-profile.md`. When researching contemporary references, also read [trend-filter.md](references/trend-filter.md). During production or critique, read [anti-slop-signals.md](references/anti-slop-signals.md).

## Required judgment

- Extract a project-specific Brand DNA rather than applying a default aesthetic.
- Define what should feel familiar, what should feel distinctive, and why.
- Choose composition, typography, imagery, density, motion, and UI conventions as one coherent system.
- Use references to identify transferable principles. Never reproduce a reference's distinctive composition or expression.
- Make unrelated brands visibly different across more than color. Vary structure, typography, spacing, image behavior, graphic language, and interaction character where the brief supports it.
- Keep the same brand coherent across screens through controlled variation, not repeated templates or blind randomness.

The final test is not whether the design looks fashionable. It is whether the design feels inevitable for this brand, useful to this audience, current without being disposable, and authored rather than assembled.
