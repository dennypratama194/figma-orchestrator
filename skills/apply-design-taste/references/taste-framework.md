# Taste framework

## 1. Brand DNA

Derive five to seven useful axes from evidence. Choose axes that affect visual decisions, such as restrained–expressive, institutional–human, technical–editorial, dense–spacious, quiet–energetic, familiar–experimental, or utilitarian–luxurious.

For every axis record:

- position and confidence;
- evidence from the brief, product, brand, audience, or content;
- resulting design behavior;
- behavior that would contradict it.

Do not force the same axes onto every project.

## 2. Familiarity and distinction

Define:

- conventions the audience must recognize immediately;
- places where surprise would create useful memorability;
- places where surprise would damage comprehension, trust, or task speed.

A good direction usually has one dominant idea and a small number of supporting moves. When every section tries to be the signature moment, nothing is.

## 3. Composition strategy

Plan page rhythm before styling individual modules. Establish where density rises, where space creates emphasis, how narrative advances, and how repeated patterns are interrupted deliberately.

Use hierarchy through scale, contrast, position, pacing, cropping, alignment, and content sequence. Do not rely on card borders and background-color changes to explain every relationship.

## 4. Material choices

Specify functional roles for typography, color, imagery, shape, line, texture, iconography, and motion. Every expressive device needs a relationship to brand character or user comprehension.

Default to solid semantic color roles. Admit a gradient or shader only when it performs a project-specific communication or brand function that survives the no-effect fallback test. Glow and color interpolation are not concepts by themselves.

Typography is structural. Select type for voice, legibility, language coverage, available weights, realistic loading, and hierarchy. Avoid using fashionable typefaces as a substitute for composition.

Imagery needs an art direction: subject, framing, crop, lighting, color treatment, repetition rules, and relationship to text. Do not fill image boxes with generic stock or synthetic-looking scenes that weaken credibility.

## 5. Quality judgment

Score each proposed direction from 1–5 with evidence:

| Dimension | Question |
|---|---|
| Strategic fit | Does it express the positioning and support the primary action? |
| Brand specificity | Could this system belong to a close competitor unchanged? |
| Hierarchy | Is attention intentionally sequenced rather than evenly distributed? |
| Composition | Does the page have rhythm, tension, balance, and deliberate variation? |
| Content truth | Are claims, product evidence, and imagery credible? |
| Contemporary relevance | Does it feel current for the audience without chasing novelty? |
| Craft | Are typography, spacing, alignment, components, and states resolved? |
| Responsive integrity | Does the idea survive constrained screens? |
| Implementation value | Is complexity justified by visible user or brand value? |

Scores expose weak reasoning; they do not replace judgment. A direction with any dimension below 3 requires revision before presentation. A high average cannot hide a blocker.
